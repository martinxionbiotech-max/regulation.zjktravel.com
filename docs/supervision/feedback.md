# 监督反馈

## 您的每一次监督，都是我们进步的动力

美景国际旅行社欢迎广大游客和社会各界对我们的经营行为进行监督。如果您在游览本网站或线下消费过程中发现以下任何问题，欢迎向我们反馈：

---

## 📌 可反馈的事项范围

| 类别 | 举例 |
|------|------|
| 资质问题 | 证照过期、名称不符、许可范围不符 |
| 资金问题 | 要求私人账户收款、拒开发票、加收税点 |
| 服务问题 | 强制消费、行程缩水、无证导游、强制购物 |
| 宣传问题 | 线上虚假宣传、价格误导、承诺未写入合同 |
| 其他合规问题 | 合同不规范、保险缺失、其他违规经营行为 |

## ❓ 常见问题

### Q1: 反馈问题后多久能收到回复？
**答：** 我们承诺在1个工作日内确认收到反馈，3-5个工作日内完成调查核实，5-7个工作日内给出具体整改回复或解释说明。较复杂的问题可能需要更长时间，我们会主动沟通进度。

### Q2: 反馈的内容会不会泄露我的个人信息？
**答：** 我们严格保护反馈人的隐私信息。未经本人书面同意，绝不对外公开姓名、联系方式等个人信息。如需在站内公开回复的典型案例，我们会与您沟通并做脱敏处理后发布。

### Q3: 如果我对美景国旅的处理结果不满意怎么办？
**答：** 如果您对我们的处理结果不满意，仍然可以通过官方渠道维权：12301全国旅游服务热线、12345政务服务热线、或拨打12315消费者投诉热线。详见[纠纷解决指南](/dispute-resolution/index/)。
