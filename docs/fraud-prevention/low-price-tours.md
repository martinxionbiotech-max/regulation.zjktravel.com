# 🏷️ 不合理低价游陷阱

> "¥99坝上一日游"、"¥199崇礼滑雪全包"——看到这样的价格，先问一句：**成本够吗？**

---

## 什么是不合理低价游？

根据《中华人民共和国旅游法》及相关司法解释，**不合理低价游**是指旅行社以低于旅游产品经营成本的价格招徕游客，通过强制购物、另行收费等途径获取不正当利益的经营行为。

**简单判断标准**：如果套餐价格连交通费 + 门票费 + 住宿费都覆盖不了，剩下的缺口一定会在您身上补回来。

## 隐形消费套路拆解

低价团有成熟的"剧本"，每一步都在设计消费：

### 1️⃣ 低价引流
在抖音、小红书、微信群发布远低于市场价的旅行产品，文案通常包含"限时抢购""最后5个名额"等话术制造紧迫感。

### 2️⃣ 上车加价
游客上车后，导游以"费用不含""需要统一安排"为由强制加收费用：
- 强制骑马：¥200/人（实际市场价¥80-100）
- 午餐自费：¥80/人（实际成本¥30）
- 景区交通：¥50/人（实际成本¥10-20）
- 保险费：¥30/人（实际保费¥2-5/天）

### 3️⃣ 购物店返点
带游客前往合作购物店，停留时间动辄1-2小时。商品价格虚高3-5倍，导游按消费额的30%-50%拿返点。不买东西？导游脸色难看，甚至"不买够金额不发车"。

### 4️⃣ 合同模糊处理
低价团的合同通常对费用包含/不包含部分一笔带过，用"以实际产生为准"等模糊表述掩盖隐形消费。

## 法律依据

**《中华人民共和国旅游法》第35条**：

> 旅行社不得以不合理的低价组织旅游活动，诱骗旅游者，并通过安排购物或者另行付费旅游项目获取回扣等不正当利益。
>
> 旅行社组织、接待旅游者，不得指定具体购物场所，不得安排另行付费旅游项目。但是，经双方协商一致或者旅游者要求，且不影响其他旅游者行程安排的除外。

**违反后果**：旅游者有权在行程结束后30日内，要求旅行社为其办理退货并先行垫付退货货款，或者退还另行付费旅游项目的费用。

## 避坑指南

| 检查项 | 怎么做 |
|:-------|:-------|
| ✅ 价格合理性 | 对比当地平均报价，低于市场价50%以上的需警惕 |
| ✅ 询问隐形消费 | 直接问："除了报价之外，还有没有必须交的其他费用？" |
| ✅ 合同条款核对 | 仔细看"费用包含"和"费用不包含"部分，逐条确认 |
| ✅ 选择正规旅行社 | 通过[全国旅游监管服务平台](https://data.zjktravel.com)核验经营许可 |
| ✅ 对公账户付款 | 只向旅行社对公账户转账，绝不向个人账户付款 |

## 美景国际旅行社的承诺

美景国际旅行社所有产品**价格透明**，签约前提供**完整费用清单**，明确列出：
- 费用包含项（交通、住宿、门票、餐饮标准）
- 费用不包含项（如有自费项目，标注自愿选择及参考价格）
- 无任何强制购物安排
- 对公账户收款，开具正规旅游服务发票
