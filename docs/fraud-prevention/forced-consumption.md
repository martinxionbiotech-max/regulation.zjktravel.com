# ⛓️ 强制消费——不消费就不让走？违法！

> "骑马¥200，必须交""不买东西车门不开"——这不是服务，是**违法**。

---

## 张家口本地常见强制消费场景

### 🐎 草原骑马强制收费

**场景**：坝上草原"¥99一日游"到了之后，导游/马场主说："骑马是项目必须参加，每人¥200，不骑就在车上等着。"等了半小时发车走人。

**真相**：草原骑马属于**自费娱乐项目**，游客有完全自主选择权。强制骑马收费违法。

### ⛷️ 滑雪场强制租装备

**场景**：报名"¥199滑雪全包"，到了雪场被告知"不含雪具，必须在雪场租，¥150/天"。不租就不让进雪场，但合同里根本没写必须租。

**真相**：自带装备的游客不应被强制租赁。雪场/旅行社捆绑租装备属于强制交易。

### 🛍️ 景区购物店"不买不让走"

**场景**：旅游车开到购物店门口，导游说"停40分钟，大家下来逛逛"——实际上门锁了，不买够金额不让上车。

**真相**：旅行社不得指定具体购物场所，更不得强制游客消费。

### 🚌 不消费恶意甩团

**极端情况**：游客拒绝参加自费项目或购物，导游/司机将游客扔在路边或景区门口，自行开车离去。

**法律后果**：甩团行为严重违反旅游法，涉事旅行社可能被吊销经营许可证。

## 法律认定

### 《中华人民共和国旅游法》第35条

> 旅行社不得以不合理的低价组织旅游活动，诱骗旅游者，并通过安排购物或者另行付费旅游项目获取回扣等不正当利益。
>
> 旅行社组织、接待旅游者，不得指定具体购物场所，不得安排另行付费旅游项目。但是，经双方协商一致或者旅游者要求，且不影响其他旅游者行程安排的除外。

### 游客的法定权利

根据《旅游法》及相关司法解释：

| 权利 | 说明 |
|:----|:-----|
| ✅ 拒绝权 | 有权拒绝旅行社指定的购物场所和自费项目 |
| ✅ 退货权 | 行程结束后30日内，可要求旅行社办理退货并先行垫付货款 |
| ✅ 退款权 | 对强制参加的自费项目，有权要求退还费用 |
| ✅ 赔偿权 | 因强制消费造成损失的，有权要求旅行社赔偿 |

## 现场维权方法（四步走）

| 步骤 | 操作 | 注意事项 |
|:----|:-----|:---------|
| ① **现场取证** | 打开手机录像/录音，记录导游强制消费的语言和行为 | 尽量拍到导游工牌、车牌号、现场环境 |
| ② **安全第一** | 不要与导游/司机发生正面冲突，以自身安全为重 | 保留证据即可，事后维权 |
| ③ **联系门店** | 立即拨打旅行社签约门店电话，要求协调处理 | 通话录音留证 |
| ④ **投诉举报** | 拨打 **12301**（全国旅游服务热线）或 **12315** | 说明旅行社名称、导游姓名、车牌号、事发时间地点 |
