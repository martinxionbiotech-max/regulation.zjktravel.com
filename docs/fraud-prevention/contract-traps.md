# 📝 合同陷阱——签字之前，逐字看完

> 合同不是走过场，而是您旅途权益的**最后一道防线**。

---

## 三种常见合同陷阱

### 陷阱一：空白合同先签名

**手法**：导游或销售人员拿出一份合同，说"先签个名，内容我们后面统一填"，或者合同关键部分（行程、费用、日期）留白。

**后果**：签名之后，对方可以在空白处填写任何对自己有利的内容。您签字的文件，最终可能和当初口头商定的**完全不一样**。

**防范**：**绝不签署任何存在空白项的合同**。所有内容填写完毕后，再签字确认。

---

### 陷阱二：霸王条款

**常见表述**（看到这些请立即警惕）：

| 霸王条款 | 为什么是霸王条款 |
|:---------|:----------------|
| "一切解释权归本公司所有" | 单方面剥夺游客的合同解释权 |
| "如遇不可抗力，团费不退" | 扩大了不可抗力的免责范围，排除游客退款权利 |
| "游客中途离团，费用不予退还且需赔偿损失" | 加重游客责任，不符合公平原则 |
| "本公司有权调整行程顺序" | 过于宽泛，可能成为随意变更行程的依据 |
| "因游客自身原因造成损失，本公司概不负责" | 完全免除自身责任 |

---

### 陷阱三：口头承诺不写入合同

**手法**：销售在微信或电话中承诺"住五星级酒店""含全部景区门票""全程无购物"，但在正式合同中这些内容**只字未提**。

**后果**：法律上，口头承诺不具有合同效力。出现问题后，旅行社可以说"合同中没有这一项"，游客有苦难言。

**防范**：**所有重要承诺必须在合同中有明确文字体现**。没有写进合同的，就当不存在。

## 法律依据

**《中华人民共和国民法典》第496条（格式条款）**：

> 采用格式条款订立合同的，提供格式条款的一方应当遵循公平原则确定当事人之间的权利和义务，并采取合理的方式提示对方注意免除或者减轻其责任等与对方有重大利害关系的条款。未履行提示或者说明义务，致使对方没有注意或者理解与其有重大利害关系的条款的，对方可以主张该条款不成为合同的内容。

**《中华人民共和国民法典》第497条（无效格式条款）**：

> 有下列情形之一的，该格式条款无效：
> - （一）具有本法第一编第六章第三节和本法第506条规定的无效情形；
> - （二）提供格式条款一方不合理地免除或者减轻其责任、加重对方责任、限制对方主要权利；
> - （三）提供格式条款一方排除对方主要权利。

简单说：**"一切解释权归本公司"这类条款，在法律上是无效的。**

## 签约前逐项检查清单

在旅游合同上签字前，逐项核对以下内容：

| 检查项 | 具体要求 |
|:-------|:---------|
| ☐ 旅行社名称 | 是否与营业执照、经营许可证一致 |
| ☐ 行程安排 | 日期、景点、交通方式、住宿标准是否明确 |
| ☐ 费用包含 | 哪些项目已包含在报价内（门票、住宿、餐饮、交通） |
| ☐ 费用不包含 | 哪些项目需自费（自费项目需标注"自愿选择"） |
| ☐ 退改政策 | 出发前/后取消的退款比例及时限 |
| ☐ 违约责任 | 双方违约的赔偿标准是否对等 |
| ☐ 争议解决 | 约定仲裁或诉讼地点（建议选择游客所在地） |
| ☐ 空白项 | 所有空白是否已填写完毕，无留白 |

## ❓ 常见问题

### Q1: 在空白合同上签名有什么风险？
**答：** 风险极大。一旦你在空白合同上签了字，旅行社可以在合同空白处填写任何对你不利的内容——增加自费项目、降低住宿标准、增加免责条款等。由于合同上有你的签名，这些内容在法律上会被认定为双方合意。正确的做法是：先逐条阅读全部内容，确认无误后再签名。如有修改，双方在修改处共同签字确认。

### Q2: "行程可能会根据实际情况调整"这样的条款合理吗？
**答：** 需要具体情况具体分析。正常的"不可抗力调整"是合理的（如天气原因封路需要绕行）。但如果"调整"变成了实质性缩水——比如把5个景点减到2个、五星酒店换成三星民宿——这就不是"调整"而是违约。美景国旅的做法：行程标准写在合同里，如果因不可抗力需要调整，提前征得游客同意并保留沟通记录。

### Q3: 口头承诺的住宿标准和合同写的不一样，以哪个为准？
**答：** 以书面合同为准。虽然口头承诺在法律上也是真实意思表示（民法典规定合同形式包括口头形式），但在发生纠纷时，口说无凭、白纸黑字的合同才是法官采信的核心证据。美景国旅建议：签约前把所有口头确认的内容过一遍合同，确保合同写清楚了再签字。

### Q4: 合同中的"退改政策"要注意什么？
**答：** 关键看三点：①出发前不同时间段的退改扣费比例是否合理（出发前7天全退、3-7天扣30%、1-3天扣50%、当天扣80%是常见标准）；②是否有"不可退款"条款——完全的不可退款可能构成霸王条款；③旅行社主动取消行程的赔偿标准是否对等。美景国旅的退改政策在签约前完整告知，绝无隐形扣费。
