# 🛡️ 保险骗局——没有保险的旅途，出事就是万丈深渊

> 旅游保险不是在"多花一份钱"，而是在为**旅途中的不确定性**兜底。

---

## 两种保险，别搞混了

很多游客分不清"旅行社责任险"和"旅游意外险"，这正是保险骗局的突破口。

### 1️⃣ 旅行社责任险（旅行社必须买）

| 项目 | 说明 |
|:----|:-----|
| 投保人 | 旅行社（法定强制） |
| 保障对象 | 游客因旅行社的过失造成的人身伤亡、财产损失 |
| 法律依据 | 《旅行社条例》第38条——旅行社应当投保旅行社责任险 |
| 保障范围 | 旅行社安排的交通、住宿、餐饮、游览等环节中的责任事故 |

**关键点**：这是旅行社**必须购买**的强制保险。如果旅行社没有购买责任险，属于违法经营。

### 2️⃣ 旅游意外险（建议游客买）

| 项目 | 说明 |
|:----|:-----|
| 投保人 | 游客（自愿购买） |
| 保障对象 | 游客在旅途中发生意外事故 |
| 保障范围 | 意外身故/伤残、意外医疗、紧急救援、行李丢失等 |

**关键点**：建议游客自行购买。正规旅行社通常会主动推荐并提供购买渠道。

## 常见保险骗局

### ❌ 骗局一：不买旅行社责任险

一些无资质中介或小型旅行社不购买或不续保旅行社责任险，以节省每年几万元的保费成本。

**后果**：一旦发生安全事故（交通事故、景区意外等），游客无法获得保险赔付，旅行社也无能力赔偿。

### ❌ 骗局二：给假保单

销售人员出示的保单是PS伪造的，或者在正规保险公司网站查不到记录。

**后果**：出险时保险公司告知"无此保单"或"保单已过期"。

### ❌ 骗局三：缩小保险范围

用低保额的意外险冒充足额保险，或者故意缩小保障范围（如"只保死亡，不保受伤"、"只在景区内有效，往返路上不保"）。

**后果**：出险后才发现保额远远不够或不在保障范围内。

## 如何核验保险？

| 核验步骤 | 操作方法 |
|:---------|:---------|
| ① 要求出示保单原件 | 不要只看截图，要求看保险公司出具的正规保单文件 |
| ② 核实保单信息 | 核对投保人名称是否为旅行社（非个人名） |
| ③ 查看保险期限 | 确保保期覆盖整个行程日期 |
| ④ 拨打保险公司电话验证 | 拨打保单上印制的保险公司客服电话，报保单号查真伪 |
| ⑤ 查看保险条款 | 确认保障范围、保额、免赔额等关键信息 |

## ❓ 常见问题

### Q1: 旅行社责任险和旅游意外险必须都买吗？
**答：** 旅行社责任险是旅行社必须自己购买的强制险，费用由旅行社承担，不需要游客另外付钱。旅游意外险是建议游客自行购买的商业险，费用通常几十元。责任险覆盖的是旅行社过失导致的损失，意外险覆盖的是旅行中各种意外事故。两者相互补充，建议都配置。

### Q2: 怎么确认旅行社真的买了责任险？
**答：** 您可以要求旅行社出示当年度的旅行社责任险保单，上面有保险公司名称、保单号、保险期限等信息。拿到保单号后可以拨打保险公司客服电话核验真实性。美景国旅的旅行社责任险保单在门店公示，欢迎查阅。

### Q3: 旅行社不给买意外险怎么办？
**答：** 旅行社没有强制义务为游客购买意外险（意外险是自愿购买的），但有义务提示游客购买意外险的重要性。如果旅行社没有提示，可以要求在出行前提交意外险购买确认。美景国旅的做法：在签约时明确告知意外险的作用和保费（通常¥20-50/人），由游客自愿选择是否购买。

### Q4: 假保单怎么识别？
**答：** 识别假保单的方法：①查看保单上的保险公司名称是否真实存在（可以在银保监会官网查询保险公司名录）；②拨打保单上的客服电话核验保单号是否有效；③查看保险条款是否清晰——假保单的条款往往模糊不清或照抄网上的模板。如果怀疑保单造假，建议通过正规保险公司直接购买意外险。
