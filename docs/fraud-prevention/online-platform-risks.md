# 在线旅游平台风险识别指南

> 越来越多人通过携程、飞猪、美团、抖音、小红书等在线平台预订旅游产品。但平台上的商家良莠不齐，学会识别风险是安全出行的第一步。

---

## 各大平台旅游产品特点

| 平台 | 产品类型 | 优势 | 风险点 |
|------|---------|------|-------|
| 携程/去哪儿 | 跟团游、自由行套餐 | 商家审核相对严格，售后有保障 | 部分第三方商家资质参差 |
| 飞猪 | 旅行社旗舰店、个人商家 | 旗舰店较可靠 | 个人商家需仔细核验 |
| 美团 | 景区门票、周边游 | 到店消费为主，性价比高 | 部分无资质商家上架旅游产品 |
| 抖音/快手 | 直播间旅游产品 | 直观展示、优惠力度大 | 虚假宣传高发区 |
| 小红书 | 攻略+个人博主推荐 | 真实体验分享多 | "野生地接""无资质推荐"最多 |

## 平台资质核验四步法

### 第一步：查看商家资质信息

在各大平台的商品页面或店铺主页，通常可以找到"商家资质"或"营业执照"入口。点击查看：
- 企业名称是否完整显示
- 是否同时有营业执照和旅行社经营许可证
- 是否在有效期内

### 第二步：独立核验

离开平台，到[国家企业信用信息公示系统](https://www.gsxt.gov.cn)和[全国旅游监管服务平台](https://mr.mct.gov.cn)独立核验商家信息。

### 第三步：看评价模式

- 所有评价都是好评、没有中差评 → 可能刷单
- 评价内容千篇一律、"很好""不错"重复出现 → 可能虚假评价
- 有真实差评且商家认真回复 → 比较可信
- 差评被删或"不予显示" → 警惕

### 第四步：电话确认

下单前直接拨打商家电话，确认：
- 旅行社名称是否与平台展示一致
- 对公账户信息
- 能否签纸质合同（线上签约+线下补签均可）

## 直播间旅游产品辨别

抖音等平台的直播间旅游产品是"重灾区"。注意以下信号：

| 危险信号 | 说明 |
|---------|------|
| "仅限今天""倒计时" | 制造紧迫感，不给你时间核验资质 |
| "前10名下单送XX" | 诱导冲动消费 |
| "¥99/人 全程无购物" | 99元连交通成本都不够 |
| "主播担保""平台兜底" | 出了事平台和主播都不认 |
| "加微信私聊下单" | 脱离平台交易，失去平台保障 |

## ❓ 常见问题

### Q1: 在OTA平台（携程/飞猪）下单安全吗？
**答：** 相对安全，但依然需要核验。平台的审核机制可以过滤掉部分无资质商家，但不能保证100%可靠。建议下单前走完"四步核验法"，尤其是核验商家的营业执照和经营许可证。

### Q2: 直播间买的旅游产品不想要了能退吗？
**答：** 根据《在线旅游经营服务管理暂行规定》，在线旅游经营者应当建立便捷的退款机制。如果没有使用，一般7天内可以全额退款。但具体退款政策需查看商品详情或咨询客服。如果商家拒绝退款，可以向平台投诉或拨打12301。

### Q3: 小红书博主推荐的"当地向导"靠谱吗？
**答：** 风险较高。很多自称"张家口当地人""坝上老司机"的博主实际上没有旅行社经营许可证，属于"无资质地接"。如果通过他们预订：①没有书面合同；②没有旅行社责任险；③没有质保金保障；④出了事找不到人。美景国旅建议：只与持有旅行社经营许可证的正规旅行社交易。
