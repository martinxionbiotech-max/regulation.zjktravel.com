# 法律文件

本文档包含美景国际旅行社旗下各网站（包括本法规监督站及关联子站）通用的隐私政策、服务条款和免责声明。

## 一、隐私政策

**更新日期：** 2025年1月1日

美景国际旅行社（以下简称"本社"）尊重并保护用户隐私。本隐私政策说明了我们如何收集、使用和保护您的个人信息。

### 1. 信息收集范围

本网站为纯资讯展示网站，**不主动收集用户个人信息**。仅在以下情形下可能涉及信息收集：

- **监督反馈：** 如您通过监督反馈通道联系我们，您可能需要提供姓名和联系方式以便我们回复
- **网站访问日志：** 服务器可能自动记录您的IP地址、浏览器类型、访问时间等基本信息

### 2. 信息使用

我们收集的信息仅用于以下目的：
- 回复您的监督反馈或咨询
- 改善网站内容和用户体验
- 履行法律法规要求的合规义务

### 3. 信息保护

- 我们采取合理的技术措施保护您的个人信息安全
- 未经您的明确同意，我们**不会**将您的个人信息向第三方披露，法律法规另有规定的除外

### 4. 信息保留期限

我们仅在必要期限内保留您的个人信息，超出保留期后将进行删除或匿名化处理。

### 5. 您的权利

您有权查询、更正、删除您的个人信息，或撤回同意。请通过门店电话 **15324337506** 联系我们行使上述权利。

### 6. 本政策更新

我们可能会不时更新本隐私政策，更新后的版本将在本页面公布。

本社尽合理努力确保网站信息的准确性，但不对信息的完整性、准确性和及时性做出任何明示或暗示的保证。网站信息可能存在更新延迟，**请以线下门店最新版本为准**。

## ❓ 常见问题

### Q1: 隐私政策保护我的哪些信息？
**答：** 隐私政策保护您的个人信息，包括但不限于：姓名、联系电话、身份证号、位置信息、浏览记录等。根据《个人信息保护法》，收集和使用您的个人信息需要取得您的同意，并且需要明确告知收集的目的、方式和范围。我们承诺不会将您的信息用于旅游服务以外的任何用途。

### Q2: 服务条款和免责声明有什么区别？
**答：** 服务条款是您使用本网站时需要遵守的规则，包括知识产权、使用限制、用户行为规范等。免责声明主要是对本网站内容的性质和准确性的说明——例如本站内容仅供参考、不作为合同要约、不对因依赖本站信息造成的损失承担责任。美景国旅的信息均经过核实，但建议您以线下门店的确认信息为准。
