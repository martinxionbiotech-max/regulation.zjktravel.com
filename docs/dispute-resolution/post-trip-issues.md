# 返程纠纷处理指南

## 旅行结束后发现问题怎么办？

返程后发现服务未达标、合同约定未履行、发票缺失等问题，可通过以下流程维权。

---

## 1️⃣ 内部协商（推荐首选）

大多数纠纷可以通过与旅行社直接协商解决。请按以下步骤操作：

### 准备材料

- 签署的旅游合同原件/复印件
- 对公账户转账凭证（或银行流水）
- 发票（如有）
- 宣传材料（行程单、报价单等）
- 您认为服务未达标的证据（照片、录音、聊天记录等）

### 联系门店

**门店经理电话：15324337506**

**建议话术：**
> "我是XX团的游客XXX，于X月X日至X月X日参加了贵社的XX线路。回程后发现XX问题（简洁说明），希望与贵社协商解决。我的合同编号是XXX，转账金额XXX元。请问如何安排对接？"

### 协商要点

- 明确诉求（退费比例、补偿方式、书面道歉等）
- 有理有据，出示证据
- 保留协商过程的录音/聊天记录
- 要求对方给出书面答复和时限

---

## 2️⃣ 官方投诉渠道

如内部协商未能在合理时间内（一般7个工作日）达成一致，可通过以下渠道投诉：

### 📞 12301 全国旅游服务热线

| 项目 | 内容 |
|------|------|
| 受理范围 | 旅游合同纠纷、服务质量投诉、导游违规等 |
| 拨打方式 | 直接拨打 **12301** 或通过"12301"微信公众号 |
| 所需信息 | 旅行社名称、团号、合同编号、投诉事由、诉求 |
| 处理时限 | 一般60日内办结 |

### 📞 12345 政务服务便民热线

| 项目 | 内容 |
|------|------|
| 受理范围 | 各类政务服务投诉，可转接文旅部门 |
| 拨打方式 | 直接拨打 **12345** |
| 优势 | 覆盖面广，可转接至地方文旅局具体处理 |

### 📞 张家口市文旅局投诉电话

| 项目 | 内容 |
|------|------|
| 受理范围 | 针对张家口本地旅行社的投诉 |
| 获取方式 | 拨打 12345 转接文旅局，或查询张家口市文旅局官网 |
| 建议 | 可先通过 12345 转接 |

### 📞 12315 市场监督投诉热线

| 项目 | 内容 |
|------|------|
| 受理范围 | 消费欺诈、虚假宣传、价格违法、合同纠纷等 |
| 拨打方式 | 直接拨打 **12315** |
| 适用场景 | 涉及虚假广告、价格欺诈、拒开发票等问题 |

## 3️⃣ 质保金赔付申请

根据《旅行社条例》，在以下情形下游客可申请使用旅行社质量保证金进行赔付：

### 适用条件

| 情形 | 说明 |
|------|------|
| 旅行社拒绝履行合同 | 擅自变更行程、甩团、拒绝提供服务等 |
| 旅行社因解散/破产造成游客损失 | 尚未退还的团费 |
| 法院判决/仲裁裁决旅行社应赔付但拒不执行 | 可申请从质保金中直接划扣 |

### 申请流程

1. 向文旅局提交书面赔付申请
2. 提供合同、付款凭证、损失证明等材料
3. 文旅局审核后通知银行划拨质保金
4. 质保金赔付金额以实际损失为限

---

## 4️⃣ 仲裁与诉讼

对于金额较大或争议复杂的纠纷，可考虑以下法律途径：

### 🔹 仲裁

- **前提条件：** 合同中约定了仲裁条款，或双方事后达成仲裁协议
- **优势：** 一裁终局、程序相对快捷、不公开审理
- **机构：** 一般为合同约定的仲裁委员会

### 🔹 诉讼

- **管辖法院：** 旅行社所在地人民法院（张家口市）
- **诉讼时效：** 一般三年，从知道权利受损之日起算
- **建议：** 金额较大（通常5000元以上）或协商无果时考虑
- **注意：** 建议先咨询律师，评估诉讼成本与胜诉可能性

## ❓ 常见问题

### Q1: 返程后多久之内可以投诉？
**答：** 通过文旅部门投诉的时效是旅游合同结束之日起90天内。通过民事诉讼途径维权的诉讼时效是3年（民法典第188条）。建议：回来后尽快整理材料进行投诉——时间越长，证据越难收集，对方也越容易以"时间已久"为由推脱。

### Q2: 12301投诉的流程是怎样的？
**答：** 12301投诉流程：①拨打12301 → ②话务员记录投诉信息和诉求 → ③转至属地文旅部门处理 → ④文旅部门5个工作日内决定是否受理 → ⑤受理后60日内作出处理决定（可延长30日）。投诉时需要提供：旅游合同、付款凭证、违约证据材料。建议投诉前先整理好材料，提高效率。

### Q3: 通过12301调解不成功怎么办？
**答：** 如果12301调解不成，后续途径包括：①申请旅行社质量保证金赔付（如果符合条件）；②申请仲裁（需要合同中约定了仲裁条款或双方事后达成仲裁协议）；③向人民法院提起诉讼（路径：合同履行地或被告住所地法院）。三种途径各有优劣，金额较小（¥5000以下）建议走调解，金额较大的可以考虑诉讼。
