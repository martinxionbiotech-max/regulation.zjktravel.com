# 证据留存指南

## 维权成功的关键在于证据

无论遇到何种纠纷，充分的证据是维权成功的基础。本指南详细列出您在旅游消费全流程中应当留存的各类证据。

---

## 📋 必备证据清单

### 1️⃣ 旅游合同 ★★★★★

| 项目 | 说明 |
|------|------|
| **留存原因** | 合同是确定双方权利义务的核心文件 |
| **留存方法** | 索取纸质合同原件，或签署电子合同并保存PDF版本 |
| **核验要点** | 合同上须加盖旅行社公章；核对合同编号、行程标准、价格、双方签字/盖章 |
| **注意事项** | 确保合同内容与销售人员口头承诺一致；如有附加条款，确认已在合同中载明 |

---

### 2️⃣ 对公转账凭证 ★★★★★

| 项目 | 说明 |
|------|------|
| **留存原因** | 证明您已向旅行社支付了约定费用 |
| **留存方法** | 保存银行转账截图、手机银行回单、柜台汇款回执 |
| **核验要点** | 收款方名称须为「张家口美景国际旅行社有限公司」；金额与合同一致 |
| **注意事项** | **切勿向个人账户转账**；如已误转个人账户，请立即联系门店经理处理 |

---

### 3️⃣ 正规发票 ★★★★★

| 项目 | 说明 |
|------|------|
| **留存原因** | 证明旅行社正式收取费用并纳税，是维权的重要凭证 |
| **留存方法** | 索取电子发票（推荐，可永久保存）或纸质发票 |
| **核验要点** | 发票内容应为「旅游服务」；开票方名称须与旅行社营业执照一致；金额与实际支付一致 |
| **注意事项** | 如旅行社拒开发票，保存拒开证据（录音/聊天截图）并立即通过[反馈通道](/supervision/feedback.md)举报 |

---

### 4️⃣ 保险单据 ★★★★

| 项目 | 说明 |
|------|------|
| **留存原因** | 旅行社责任险及个人意外险是出险后的理赔依据 |
| **留存方法** | 要求旅行社提供责任险保单复印件；自愿购买的意外险应收到电子保单 |
| **核验要点** | 核对保险期间是否覆盖出行日期；核对保额和保障范围 |
| **注意事项** | 出发前未收到保单的，应主动索要 |

---

### 5️⃣ 宣传材料 ★★★★

| 项目 | 说明 |
|------|------|
| **留存原因** | 销售人员展示的行程单、报价单、宣传册等是证明承诺内容的重要依据 |
| **留存方法** | 保存纸质宣传单；对电子宣传材料（微信聊天、网页截图）进行截图或拍照 |
| **核验要点** | 宣传内容应当与合同一致；不一致时宣传材料可作为"虚假宣传"的证据 |
| **注意事项** | 注意：本网站内容不作为合同附件，线下销售人员提供的书面材料才具有参考价值 |

---

### 6️⃣ 聊天记录 ★★★★

| 项目 | 说明 |
|------|------|
| **留存原因** | 与销售人员的微信聊天、短信、通话录音可佐证双方的约定 |
| **留存方法** | 微信聊天记录建议定期备份（设置→通用→聊天记录迁移与备份）；重要对话截图保存 |
| **核验要点** | 确认对方身份（与旅行社关联）；保留完整的对话上下文，不要只截图部分内容 |
| **注意事项** | 微信聊天记录在诉讼中可作为电子证据使用，但需注意原始性要求 |

---

### 7️⃣ 行程中证据 ★★★

| 项目 | 说明 |
|------|------|
| **留存原因** | 行程中出现问题时的现场证据 |
| **留存方法** | 拍摄住宿酒店、餐食、车辆、景点等实际情况；录制导游服务过程 |
| **核验要点** | 照片/视频中最好包含时间水印或能够证明拍摄时间的信息 |
| **注意事项** | 合法范围内取证，不得侵犯他人隐私权；他人肖像权问题需注意 |

---

### 8️⃣ 现场见证人信息 ★★★

| 项目 | 说明 |
|------|------|
| **留存原因** | 同行游客的证言可作为辅助证据 |
| **留存方法** | 留档1-2位同行游客的联系方式（姓名+电话） |
| **核验要点** | 确认对方愿意作证；记录对方的基本信息 |
| **注意事项** | 尊重他人意愿，不得强迫作证 |

## ⚠️ 重要提示

1. **所有证据建议云备份+本地双重保存**
2. **电子证据注意保留原始文件，不要编辑修改**
3. **微信聊天记录作为证据时，建议通过腾讯电子取证平台固定**
4. **涉及金额较大的纠纷，建议咨询律师后系统整理证据链**
5. **维权过程中所有与旅行社的沟通尽量留下文字记录**

## ❓ 常见问题

### Q1: 微信聊天记录能作为证据吗？
**答：** 可以。微信聊天记录属于电子数据证据，在法律上是有效的证据形式。但需要注意：①保留原始记录——截图可能被质疑，需要保留原始聊天记录（不要删除）；②确认对方身份——微信昵称不等于真实身份，建议在聊天中确认对方全名和职务；③完整性——不要只截取有利的部分，应提供完整的聊天记录。转账记录同样建议保留完整的银行流水。

### Q2: 没有合同只有转账记录能维权吗？
**答：** 比完全没有任何证据要好，但仍然不够充分。转账记录能证明你付了钱，但不能证明这笔钱是付给谁的、用于什么服务的。如果可能，尽量补齐：①向旅行社索要收款凭证或发票；②要求旅行社出具服务内容确认函；③找出与旅行社的聊天记录或通话录音，确认服务内容和金额。最好的还是签约时签书面合同。

### Q3: 录音证据需要告知对方吗？
**答：** 在中国法律中，**非以侵害他人合法权益或违反法律禁止性规定的方式取得的录音，可以作为证据使用**。也就是说，在公开场合录制与导游/旅行社工作人员的对话（涉及纠纷的部分），即使没有提前告知对方，只要不涉及窃听、非法侵入等违法手段，一般可以作为证据。但如果您在对方的办公室等私人空间录音，可能需要视具体情况判断合法性。
