# 《旅游投诉处理办法》全文解读

> **发布机关**：国家旅游局（现文化和旅游部）
>
> **施行时间**：2010年7月1日
>
> **官方原文**：[文化和旅游部 · 旅游投诉处理办法](https://www.mct.gov.cn/whzx/ggtz/202009/t20200921_875434.htm)

---

## 一、投诉受理条件（办法第8–11条）

### 可以投诉的情形

> 投诉人可以就下列事项向旅游投诉处理机构投诉：
>
> （一）认为旅游经营者违反合同约定的；
>
> （二）因旅游经营者的责任致使投诉人人身、财产受到损害的；
>
> （三）因不可抗力、意外事件致使旅游合同不能履行或者不能完全履行，投诉人与被投诉人发生争议的；
>
> （四）其他损害旅游者合法权益的。

### 投诉不予受理的情形

> 下列情形旅游投诉处理机构不予受理：
>
> （一）人民法院、仲裁机构、其他行政管理部门或者社会调解机构已经受理或者处理的；
>
> （二）旅游投诉处理机构已经作出处理，且没有新情况、新理由的；
>
> （三）不属于旅游投诉处理机构职责范围或者管辖范围的；
>
> （四）超过旅游合同结束之日**90天**的；
>
> （五）不符合本办法第十条规定的投诉人条件的；
>
> （六）本办法规定情形之外的其他经济纠纷。

> ⭐ **游客重点条款**
>
> **投诉时效：旅游结束后90天内。** 超过90天，旅游投诉处理机构将不再受理。请务必在返程后尽快提出投诉。

| 投诉渠道 | 联系方式 | 说明 |
|---------|---------|------|
| 全国旅游服务热线 | **12301** | 全国统一旅游投诉热线 |
| 政务服务便民热线 | **12345** | 可转接至旅游主管部门 |
| 消费者投诉热线 | **12315** | 涉及消费欺诈、价格违法等 |
| 文旅部官网投诉 | [https://www.mct.gov.cn](https://www.mct.gov.cn) | 在线提交投诉 |
| 属地旅游主管部门 | 当地文旅局投诉电话 | 直接向事发地或旅行社所在地文旅局投诉 |

## 三、投诉处理流程

```
受  理  ──→  调  查  ──→  调  解  ──→  终止调解或达成协议
  │                │                 │
  │                │                 ├── 达成协议 → 履行
  │                │                 └── 调解不成 → 终止调解
  │                │
  │                └── 不符合条件 → 不予受理（书面告知理由）
  │
  └── 符合条件 → 5个工作日内决定是否受理
```

### 流程详解

**第1步：受理（5个工作日）**
旅游投诉处理机构在收到投诉之日起5个工作日内，作出是否受理的决定，并书面通知投诉人。

**第2步：调查（30日）**
受理后30日内进行调查核实。情况复杂的，经批准可以延长30日。

**第3步：调解**
在查明事实的基础上，遵循自愿、合法的原则进行调解。

**第4步：终止调解或达成协议**
- 双方达成调解协议 → 制作调解协议书
- 无法达成协议 → 终止调解，出具终止调解通知书

## 四、调解不成怎么办？

调解不是终点。调解失败后，游客还有以下法律途径：

| 途径 | 说明 | 适用场景 |
|------|------|---------|
| **仲裁** | 提交有管辖权的仲裁机构 | 合同中约定了仲裁条款 |
| **诉讼** | 向人民法院提起诉讼 | 任何旅游纠纷均可 |
| **消费者协会调解** | 向消协投诉 | 消费类争议 |
| **质保金划拨** | 向旅游主管部门申请划拨旅行社质保金 | 旅行社拒绝赔偿或倒闭跑路 |

> ⭐ **游客重点条款**
>
> **质保金划拨条件**（《旅行社条例》第15条）：
> 旅行社违反合同约定侵害游客权益，经查证属实的，或旅行社破产解散导致游客预交费用损失的，旅游主管部门可从质保金中划拨赔偿。
>
> **诉讼路径**：向人民法院提起诉讼的时效为**3年**（民法典第188条），比旅游投诉的90天时效宽裕得多。建议先走投诉程序，投诉不成再考虑诉讼。

## 五、维权证据清单

无论选择哪种维权方式，证据是胜诉的关键。建议游客在行程中有意识地保留以下证据：

| 证据类型 | 具体内容 | 保存方式 |
|---------|---------|---------|
| 📄 合同文件 | 旅游合同及附件、行程单、出团通知 | 纸质原件或清晰扫描件/照片 |
| 💳 付款凭证 | 银行转账记录、POS机小票、发票、收据 | 截图/拍照/保留原件 |
| 🖼️ 现场证据 | 强制购物现场照片/视频、服务不达标的实拍 | 手机拍摄（建议启动水印相机APP） |
| 💬 沟通记录 | 与旅行社、导游的微信聊天记录、短信、录音 | 截图/录屏；录音注意合法性 |
| 📝 投诉记录 | 投诉受理回执、调解记录、答复文件 | 保留书面文件原件 |

## 六、投诉实操建议

1. **先协商，后投诉**——现场发现问题第一时间与导游/领队协商，协商不成再走正式投诉
2. **投诉对象要准确**——投诉旅行社（而非导游个人），提供旅行社全名和许可证号
3. **投诉时效要抓紧**——返程后**立即整理材料并在90天内提交投诉**
4. **书面材料要完整**——包括投诉请求、事实经过、证据清单
5. **多路并行**——同时向12301和12345投诉，提高处理效率
